# ZenFlow: Dynamic Graph Recommendation

第六届计图人工智能挑战赛赛道一的参赛复现代码。

本项目面向带时间戳的图交互数据，在候选集合中预测未来可能发生的连接。核心方法采用统一的时序图推荐与候选重排序框架，结合时序统计特征、图结构特征、表示学习模型与排序模型完成预测。

## 赛事阶段

比赛分为 A 榜和 B 榜两个阶段：

| 阶段 | 数据集 | 说明 |
| --- | --- | --- |
| A 榜 | Dataset 1 / Dataset 2 | 用于方法验证与初赛评测 |
| B 榜 | Dataset 3 / Dataset 4 | 用于大规模、多场景条件下的复赛评测 |

根据赛事要求，A/B 榜使用一致的核心算法框架；针对不同数据集，仅在数据读取、节点空间、图类型、训练规模、批处理策略等工程适配层面进行调整。

## 方法概览

整体流程包括：

1. 读取历史交互与候选边；
2. 构造时序、邻域、节点活跃度和图结构特征；
3. 训练图表示学习模型与候选排序模型；
4. 对测试候选边进行打分并生成提交文件。

详情请参照 [A榜](/A/README.md) 和 [B榜](/B/README.md) README文件

项目同时考虑二部图与非二部图场景，以及不同数据规模下的训练和推理效率。

赛事数据由主办方提供，本仓库不包含原始训练数据、测试数据、测试集标签或提交结果文件。

赛事数据或任何测试集标签未提交到公开仓库。
